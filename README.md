# Sistema de Gerenciamento de Câmeras com IA

## Descrição

Sistema web para gerenciamento e monitoramento de câmeras de segurança, com recursos de visualização de câmeras, detecção de movimentos, identificação de objetos por Inteligência Artificial e registro de eventos.

## Objetivo

Facilitar o monitoramento de ambientes por meio de uma interface web organizada, permitindo acompanhar câmeras, analisar eventos e consultar resultados da Inteligência Artificial.

## Funcionalidades previstas

- Autenticação de usuários;
- Cadastro e gerenciamento de câmeras;
- Visualização do status das câmeras;
- Detecção de movimento;
- Identificação de objetos por IA;
- Registro de eventos e ocorrências;
- Consulta de histórico;
- Configurações e perfil do usuário.

## Estrutura do repositório

- `RT02.md` — documentação principal do trabalho;
- `arquitetura.svg` — diagrama da arquitetura do sistema;
- `wireframes.svg` — protótipo inicial das telas;
- `planejamento.csv` — planejamento das atividades;
- `.editorconfig` — padronização do editor;
- `.gitignore` — arquivos ignorados pelo Git;
- `.prettierrc.json` — configuração de formatação;
- `.env.example` — exemplo de variáveis de ambiente.

## Tecnologias previstas

- Frontend web;
- Backend em Python;
- Banco de dados MySQL;
- Integração com serviços de Inteligência Artificial;
- Git e GitHub para versionamento.
